🍻 다같이 만드는 회식 맛집

누구나 이 페이지에서 회식 장소를 바로 등록하고 볼 수 있게, 무료 파이어베이스(Firestore) DB를 한 번만 연결하면 돼요.

  1. 파이어베이스 콘솔에서 프로젝트를 하나 만드세요 (이름은 아무거나, 예: 과천 회식 맛집).
  2. 왼쪽 메뉴 Firestore Database → 데이터베이스 만들기 → 테스트 모드로 시작 → 가까운 리전(asia-northeast3 등) 선택.
  3. Firestore 규칙(Rules) 탭에서 아래처럼 바꾸고 게시하세요 (로그인 없이 다같이 쓰는 내부용이라 읽기/쓰기를 열어둬요 — URL을 아는 누구나 쓰고 지울 수 있다는 뜻이니 참고하세요): 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gwacheonRestaurants/{doc} {
      allow read, write: if true;
    }
  }
}
  4. 프로젝트 설정(⚙️ 톱니바퀴) → 일반 → "내 앱" → 웹 앱 추가(</> 아이콘) → 앱 등록 → 나오는 firebaseConfig 객체({`{ apiKey: ...`} 부분) 전체를 복사하세요.
  5. 아래 칸에 그대로 붙여넣고 저장하세요. 이 값은 깃허브에 올라가지 않고 이 브라우저에만 저장돼요.
설정을 읽지 못했어요. firebaseConfig 객체를 그대로 붙여넣었는지, Firestore 규칙을 게시했는지 확인해 주세요.
등록에 실패했어요. 잠시 후 다시 시도해 주세요.

카카오맵 JavaScript 키가 필요해요

지도는 카카오맵 API로 그려집니다. 아래 순서대로 무료 키를 발급받아 붙여넣으면 바로 쓸 수 있어요.

  1. 카카오 개발자 사이트에서 로그인 후 애플리케이션을 하나 추가하세요.
  2. 앱 요약 정보의 JavaScript 키를 복사하세요.
  3. 앱 설정 → 플랫폼 → Web 플랫폼 등록에 이 페이지 주소(예: https://happimin38.github.io)를 추가하세요.
  4. 아래 입력칸에 키를 붙여넣고 저장하세요. 키는 이 브라우저에만 저장되고 깃허브에는 올라가지 않아요.
키가 올바르지 않거나 도메인이 등록되지 않았어요. 플랫폼 설정을 다시 확인해 주세요.

⭐ 저장한 맛집 (회식용)

맛집 검색은 카카오맵 API를 사용합니다. 리뷰·평점·룸 정보는 API로 제공되지 않아 "네이버 후기" 링크로 직접 확인하세요.
"다같이 만드는 회식 맛집" 목록은 파이어베이스에 저장돼 모두에게 공유되고, 이 페이지 주소를 아는 누구나 추가·삭제할 수 있어요.
개인 즐겨찾기와 인원/예산/룸 태그는 이 브라우저에만 남아요.
