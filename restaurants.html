🍻 다같이 만드는 회식 맛집

팀원들이 구글 폼으로 등록한 회식 장소를 여기 모아 보여줘요. 처음 한 번만 설정하면 돼요.

  1. 구글 폼에서 새 양식을 만들고, 다음 질문을 추가하세요: 가게 이름(단답형), 카카오맵 링크(단답형, 선택), 인원(객관식: 10인 미만 / 10~20인 / 20인 이상), 예산(객관식: 2만원대 / 3만원대 / 4만원 이상), 룸 유무(객관식: 있음 / 없음), 한줄 후기(장문형, 선택), 작성자(단답형, 선택). 괄호 안 문구는 필터가 인식하는 값이라 그대로 써주세요.
  2. 폼 편집 화면의 "응답" 탭 → 초록 스프레드시트 아이콘 클릭 → 응답이 쌓일 시트를 새로 만드세요.
  3. 그 스프레드시트에서 파일 → 공유 → 웹에 게시 → 형식을 쉼표로 구분된 값(.csv)으로 선택 → 게시 → 나오는 링크를 복사하세요.
  4. 폼 자체의 "보내기" 버튼에서 폼 링크도 복사하세요 (팀원들이 등록할 때 쓸 링크예요, 선택사항).
불러오지 못했어요. CSV 링크가 맞는지, 시트가 "웹에 게시" 상태인지 확인해 주세요.

카카오맵 JavaScript 키가 필요해요

지도는 카카오맵 API로 그려집니다. 아래 순서대로 무료 키를 발급받아 붙여넣으면 바로 쓸 수 있어요.

  1. 카카오 개발자 사이트에서 로그인 후 애플리케이션을 하나 추가하세요.
  2. 앱 요약 정보의 JavaScript 키를 복사하세요.
  3. 앱 설정 → 플랫폼 → Web 플랫폼 등록에 이 페이지 주소(예: https://happimin38.github.io)를 추가하세요.
  4. 아래 입력칸에 키를 붙여넣고 저장하세요. 키는 이 브라우저에만 저장되고 깃허브에는 올라가지 않아요.
키가 올바르지 않거나 도메인이 등록되지 않았어요. 플랫폼 설정을 다시 확인해 주세요.
